모바일 웨딩 청첩장

실행: index.html을 브라우저에서 열면 됩니다.
권장: 복사 기능을 안정적으로 사용하려면 VS Code Live Server 또는 HTTPS 환경에서 실행하세요.

파일 구성
- index.html : 페이지 내용 및 구조
- css/style.css : 디자인과 반응형 레이아웃
- js/main.js : 사진 확대 팝업, 계좌번호 복사 팝업
- assets/ : 시안에서 추출한 실제 웨딩 사진 이미지

실제 사용 전 수정할 항목
1. index.html에서 이름, 날짜, 시간, 예식장 주소를 실제 정보로 변경
2. data-copy 값에 실제 계좌번호를 입력하고 은행명 변경
3. Google 지도 링크의 query 값을 실제 예식장 이름/주소로 변경
4. assets 폴더의 이미지를 실제 웨딩 사진으로 교체 (파일명 유지)

참고: 현재 지도는 요청에 따라 '그랜드웨딩홀 서울' 검색으로 연결되는 예시 링크입니다.
계좌번호와 날짜/주소는 시안에 맞춘 임시 예시 정보입니다.
